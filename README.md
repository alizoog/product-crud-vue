# Product CRUD Vue

This is the frontend for the Product CRUD application. It is built using Vue.js and communicates with the backend API.

## Project Setup

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/alizoog/product-crud-vue.git
   cd product-crud-vue
   ```

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

## Features
- List all products
- Search products by name and status
- Paginate through product list
- Add a new product
- Edit an existing product
- Delete a product

## Technologies Used
- Vue.js 3
- Bootstrap for UI styling
- Axios for API requests

## Prerequisites
Make sure you have the following installed:
- Node.js 20.18.3
- npm or yarn

## Configuration
Update the API base URL in the `src/config.js` file if necessary. The backend API is hosted in the `product-crud-jersey` repository.

## Backend API
This frontend interacts with the backend API hosted in the `product-crud-jersey` repository. Make sure the backend is running before using the frontend.
